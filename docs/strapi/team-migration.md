# Перенос блока «Команда» в Strapi

На первом этапе добавлен Collection Type **Team Member** и исходный набор из
девяти участников. Порядок, имена, должности и пути к портретам повторяют
`src/components/ui/TeamSection/team.data.ts`. Портреты уже находятся в
`public/persones/`; медиафайлы и production не изменялись.

`key` сохраняет устойчивую связь записи с участником в React, а `sortOrder`
задаёт порядок. Для изображения и необязательного видео доступны как URL-поле,
так и поле Media Library. Сначала будут использоваться существующие локальные
URL. Перед использованием новых загрузок вне локальной среды потребуется
настроить REG.RU S3 и проверить доступность медиа из статического сайта.

Исходные данные находятся в `cms/data/team-members.seed.json`. На этом этапе
они **не импортированы** в базу Strapi; сайт продолжает использовать локальный
`team.data.ts`. Следующий этап — проверить данные, создать черновики в локальной
Strapi и согласовать их перед публикацией. После этого отдельным этапом будет
добавлено чтение опубликованных участников при статической сборке.

Прокрутка, бесконечный цикл, выбор активного участника, размеры плашек,
расположение портрета и анимация остаются в React/CSS. Заголовок и поясняющий
текст блока пока тоже остаются в коде; переносить их нужно отдельно как часть
редактируемых текстов страницы.
